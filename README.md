# Nebula Updater-NU 星云更新器 iOS

> 快速下载 Minecraft 模组的 iOS 客户端

## 功能

- 双模式下载 — JSON Manifest / CSV 文件
- 自定义服务器、线程数、版本文件夹
- 网络调试 — Ping 测试
- 开发者模式 — 日志查看
- iOS 文件 App 集成

## 使用

1. 打开 App，点击开始下载
2. 默认使用 JSON Manifest
3. 也可通过文件 App 上传 file_list.csv

## 技术

Kotlin Multiplatform + Compose Multiplatform + SwiftUI + NSURLSession
